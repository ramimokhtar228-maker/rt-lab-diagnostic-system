# RT LAB - معامل رامي مختار للتحاليل التشخيصية
### كلية طب قصر العيني - جامعة القاهرة
### أطباء الباثولوجيا الإكلينيكية والكيميائية

نظام إدارة نتائج وتقارير المرضى والأرشفة الإلكترونية المتكامل، مصمم خصيصاً لمعامل التحاليل الطبية والتشخيصية وفق أعلى المعايير المعتمدة.

---

## 🔬 مميزات النظام

- **الهوية البصرية لمعامل RT**: باللون الأحمر الداكن (Dark Red / Crimson) والأزرق الداكن (Navy) مع شعار قطرة الدم الكريستالية.
- **تسجيل بيانات المريض الشاملة**:
  - الاسم ثلاثي / رباعي
  - السن ووحدة العمر (سنة / شهر / يوم)
  - النوع (ذكر / أنثى)
  - رقم واتساب المباشر
  - الطبيب المعالج مع خيارات سريعة (`Prof. Dr.` / `Dr.` / `Herself` / `Himself`)
  - الباركود وتاريخ سحب العينة وإصدار النتيجة
- **ترتيب جداول التقرير من اليسار إلى اليمين**:
  1. `Investigations` (اسم الفحص وطريقة المعايرة)
  2. `Results` (النتيجة الرقمية أو الوصفية)
  3. `Coloured chart` (مؤشر لوني مرئي ثلاثي المناطق مع إبرة مؤشر دقيقة)
  4. `Flags` (الرايات والتنبيهات: Normal / High / Low / Critical)
  5. `References` (المعدلات الطبيعية ووحدات القياس)
- **كل بروفايل في صفحة مستقلة (A4 Print & PDF)**: تنسيق طباعة إلكتروني ذكي يفصل كل بروفايل في صفحة مستقلة مع ترويسة كاملة وتوقيعات معتمدة.
- **تحميل مباشر لملفات PDF**: توليد وتنزيل ملف PDF عالي الجودة مباشرة بنقرة زر واحدة.
- **تصدير العروض التقديمية (PowerPoint / .pptx)**: إنشاء وتنزيل ملف عرض تقديمي كامل لكل حالة طبية.
- **تنبيهات فورية عبر واتساب**: إرسال إشعار فوري ومعتمد للمريض عبر واتساب مباشرة.
- **كتالوج التحاليل الطبية**: أكثر من 80 فحصاً طبياً معتمداً (CBC, وظائف كبد، وظائف كلى، دهون، سكر، غدة درقية، أملاح، سيولة، هرمونات، دلالات أورام، فحص بول).
- **إضافة أي فحص يدوي**: إمكانية إضافة أي تحليل غير مدرج بالكتالوج مع تحديد المعدلات الطبيعية والوحدات.
- **التطورات البيانية لكل تحليل لكل مريض (Trend Charts)**: رسم بياني تفاعلي يوضح مسار التحاليل عبر مختلف الزيارات مع النطاق الطبيعي ومعدل التغير (Delta %).
- **إدارة الإمضاءات والاعتماد المعملي**:
  - `Lab CHEMIST` (كيميائي المعمل)
  - `Verify by` (مراجعة الجودة)
  - `Pathologist` (أ.د. رامي مختار - استشاري الباثولوجيا الإكلينيكية والكيميائية - كلية طب قصر العيني)
- **أرشيف إلكتروني متكامل**: بحث وتصفية فورية ونسخ احتياطي واسترجاع بصيغة JSON بدون أسعار.

## 🚀 التشغيل والتثبيت (Installation & Run)

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل بيئة التطوير المحلية
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

النظام يعمل على المتصفح مباشرة ويدعم العمل محلياً دون الحاجة لاتصال إنترنت دائم.
